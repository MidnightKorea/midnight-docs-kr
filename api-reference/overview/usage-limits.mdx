# Usage limits

Midnight Network에는 블록 한도와 트랜잭션 한도라는 두 종류의 사용량 한도가 있습니다.

## Block limits

Midnight은 블록당 단일 바이트 상한 대신 다차원 비용 모델을 사용합니다. 각 차원과 한도는 다음 표와 같습니다.

| Dimension | Limit per block | Description |
|-----------|-----------------|---------|
| `block_usage` (broadcast bytes)      | 200,000 bytes    | 블록에 포함된 트랜잭션 데이터의 바이트 수 |                 
| `bytes_written` (persistent writes)  | 50,000 bytes     | 디스크에 영구적으로 기록되는 순 바이트 수 |
| `bytes_churned` (temp writes)        | 1,000,000 bytes  | 일시적으로 기록되거나 덮어쓰이는 바이트 수 |
| Read time budget                   | 1 second         | 블록 내 모든 트랜잭션의 I/O 읽기 비용 |
| Compute time budget                | 1 second         | 블록 내 모든 트랜잭션의 연산 비용 |

Substrate 레이어는 전체 블록 바이트 한도로 1 MB도 부과하며, 이 중 약 786 KB(1 MB의 75%)를 일반 트랜잭션에 사용할 수 있습니다. 블록 생성 시간은 6초입니다.

## Transaction limits

최대 트랜잭션 크기는 1 MiB(1,048,576 bytes)입니다. 이는 트랜잭션 전체의 직렬화된 바이트 크기입니다.
이 한도는 형식 적합성 검증 단계에서 적용됩니다. 한도를 초과하는 트랜잭션은 `MalformedTransaction::TransactionTooLarge`로 거부됩니다.

:::info

블록 한도와 트랜잭션 한도는 모두 설정 가능한 레저 파라미터이며 거버넌스를 통해 조정할 수 있습니다.

:::

### Per account transaction limit

계정별로 하루 최대 10 MB의 트랜잭션 데이터로 제한하는 스로틀도 있습니다(블록당 6초 기준 14,400블록의 롤링 윈도우 동안 적용).
