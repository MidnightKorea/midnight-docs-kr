# Partner sprints on Midnight

Midnight은 3주마다 생태계 파트너와 함께 실습형 스프린트를 진행합니다. 2주간의 퀘스트, 마지막에 완성되는 동작하는 DApp, 그리고 파트너가 내건 상품까지. [Midnames](https://midnight.domains/)와 함께한 Sprint 1이 막 끝났고, [1AM](https://1am.xyz/)과 함께하는 Sprint 2가 지금 진행 중입니다.

이 글에서는 Sprint 1이 어떻게 진행됐는지 돌아보고, 막 시작된 1AM 스프린트에 어떤 내용이 담겨 있는지 소개합니다.

## How partner sprints work

Midnight은 3주마다 새로운 생태계 파트너와 함께 스프린트를 시작합니다. 진행 방식은 단순합니다:

- **2주** 동안 퀘스트를 완료합니다.
- 스프린트 사이에 **1주** 휴식이 있습니다.
- 매번 파트너가 **실제 상품**을 겁니다.

각 스프린트는 잘 짜인 하나의 트레일입니다. 파트너의 웹사이트·문서·SDK로 안내하는 길잡이와, 그 자료를 실제로 써먹게 하는 퀘스트로 구성됩니다. 스프린트를 끝낼 즈음이면 파트너의 제품을 직접 다뤄 보고, 그 위에서 무언가를 만들어 본 상태가 됩니다.

함께하고 싶다면 [Zealy hub](https://zealy.io/cw/midnightnetwork)가 베이스캠프입니다. 스프린트는 이곳에서 돌아가며 열립니다.

## Sprint 1 recap: Midnames

첫 번째 스프린트는 Midnight의 신원 레이어인 [Midnames](https://midnight.domains/)를 빌더들에게 소개했습니다. Midnames로는 사람이 읽을 수 있는 .night 이름을 등록하고, 거기에 데이터를 붙이고, 어떤 앱에서든 그 이름을 resolve할 수 있습니다. 자신에 관한 모든 것을 드러내지 않으면서도 온체인 신원을 읽기 쉽게 만드는 방법입니다.

스프린트 기간은 끝났지만, 퀘스트는 [Zealy hub](https://zealy.io/cw/midnightnetwork)의 상설 모듈로 남아 있습니다. Midnames를 다뤄 보고 싶은 사람은 언제든 이 트레일을 따라갈 수 있습니다. 모듈은 여섯 개의 퀘스트로 구성됩니다:

1. **Explore Midnames**: Midnames와 midnight.domains 사이트를 둘러보며 감을 잡습니다.
2. **Claim your .night domain on preprod**: Quest 2를 마치면 자신만의 .night 이름이 등록되어 있습니다.
3. **Configure your domain profile**: 메타데이터와 커스텀 필드를 붙여서, Midnames가 이름 그 이상으로 신원을 확장한다는 것을 확인합니다.
4. **Explore the Midnames SDK**: 코드를 작성하기 전에 문서를 읽습니다.
5. **Query your domain data**: SDK를 로컬에서 사용해 자신의 프로필을 가져오고, resolver가 자신의 머신에서 끝까지 동작하는 것을 증명합니다.
6. **Build a Midnames-powered DApp**: .night 이름 resolve, 프로필 데이터 조회, UI 흐름에서의 활용 중 적어도 하나를 수행하는 무언가를 만들어 출시합니다. 프로필 뷰어, 신원 대시보드, 도메인 기반 로그인 — 무엇이든 좋습니다.

Quest 5에서는 빌더들이 SDK를 설치하고, 작은 resolver 스크립트를 저장한 뒤, 자신의 도메인을 대상으로 실행해 봤습니다. 대략 이런 흐름입니다:

```bash
npm install @midnames/sdk
npm pkg set type=module
```

다음 내용을 `resolve.ts`로 저장합니다:

```typescript
import { createDefaultProvider, getDomainProfile } from "@midnames/sdk";

const domain = process.argv[2];
const provider = createDefaultProvider({ networkId: "preprod" });
const result = await getDomainProfile(domain, { provider });
console.log(result.data);
```

그리고 preprod에 등록된 아무 .night 도메인이나 넣고 실행합니다:

```bash
npx tsx resolve.ts mid.night
```

## Sprint 2 is live: 1AM

Sprint 2는 Midnight 전용으로 만들어진 지갑인 [1AM](https://1am.xyz/)과 함께 막 시작됐습니다. 1AM은 Midnight의 이중 상태 아키텍처에 맞춰 설계됐습니다. shielded 트랜잭션이 기본값이고, NIGHT과 DUST를 하나의 인터페이스에서 다루며, ZK proof 생성을 위한 Proof Station을 제공합니다.

1AM 스프린트는 지갑, explorer, Proof Station, 노코드 빌더, DApp 등록 절차까지 아우르는 여덟 개의 퀘스트로 구성됩니다:

1. **Explore 1AM**: 지갑, 노코드 빌더, explorer, Proof Station에 익숙해집니다.
2. **Follow 1AM on X**: 제품 업데이트 소식을 바로 받아 봅니다.
3. **Create your 1AM wallet**: 이 지갑이 남은 스프린트 동안 여러분의 신원이 됩니다.
4. **Explore the 1AM Explorer**: 무엇이 추적되고, 무엇이 표시되고, 무엇이 비공개로 남는지 확인합니다.
5. **Visit the 1AM Proof Station**: 1AM 기반 DApp에서 Proof Station이 맡는 역할을 이해합니다.
6. **Build with the 1AM no-code builder**: [build.1am.xyz](https://build.1am.xyz/)에서 프로젝트를 만들어 공유 링크를 제출합니다.
7. **Build a 1AM-powered DApp**: 노코드 너머로 갑니다. 지갑 연결, 실제 Proof Station 연동, 다른 개발자가 실행하거나 확장할 수 있는 코드까지.
8. **List your DApp on 1AM**: 만든 DApp을 1AM 공개 디렉터리에 등록합니다.

퀘스트는 순서에 상관없이 진행해도 되고, 여덟 개를 다 끝내지 않아도 참여할 수 있습니다. 1AM 스택에서 직접 만져 보고 싶은 부분을 골라잡으세요.

우수 참가자에게는 1AM이 준비한 상품이 주어지며, 자세한 내용은 [Zealy hub](https://zealy.io/cw/midnightnetwork)에서 확인할 수 있습니다.

## Jump in

파트너 스프린트는 3주마다 새로운 생태계 파트너, 새로운 관점과 함께 돌아옵니다. 지금 바로 1AM 스프린트에 합류하는 방법은 다음과 같습니다:

- [Zealy hub](https://zealy.io/cw/midnightnetwork)를 열고 1AM 스프린트 퀘스트를 시작하세요.
- Quest 3를 끝낼 수 있도록 브라우저에 [1AM 확장 프로그램](https://1am.xyz/)을 추가하세요.
- 스프린트 소식을 받으려면 [Midnight on X](https://x.com/MidnightNtwrk)와 [1AM on X](https://x.com/oneamxyz)를 팔로우하세요.

패턴은 매 스프린트 같습니다. 실제 파트너, 실제 제품, 그리고 마지막엔 실제로 동작하는 DApp. 리더보드에서 만나요.
