# Token acquisition

프로덕션 Midnight 네트워크에서는 DApp을 실행하는 모든 사용자가 영구 지갑에 DUST를 보유하고 각 transaction마다 일부를 수수료로 지불해야 합니다. 하지만 Testnet에서는 Midnight DApp을 실험하려는 개발자를 위해 무료 tDUST가 제공됩니다.

## Get tDUST

1. Lace 지갑에서 수신 주소를 복사하세요.

  :::note Bech32m Address Format
  모든 지갑 주소는 기본적으로 Bech32m 형식으로 표시됩니다. faucet은 두 가지 형식을 모두 지원하지만, 레거시(HEX) 형식은 향후 버전에서 제거될 예정입니다.
  :::

2. [Midnight testnet faucet 🚰](https://midnight.network/test-faucet/)에 방문하여 지갑 주소를 입력하세요.
3. **Request tokens** 을 클릭하세요. 처리에 몇 초가 걸리며, 다음과 같은 결과가 반환됩니다:

`Transaction submitted. Its ID is 1644b988ac71dc6bd6...`

4. faucet에서 1000.0 tDUST를 받았을 것입니다.
