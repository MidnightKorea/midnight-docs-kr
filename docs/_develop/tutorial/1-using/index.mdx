# Using Midnight

Midnight 개발자 튜토리얼의 첫 번째 파트에서는 다음을 진행합니다:

1. Midnight 네트워크에 연결하는 데 필요한 구성 요소를 설치하고 설정합니다.
2. 네트워크에서 transaction 수수료로 사용할 tDUST를 받습니다.
3. 네트워크에 연결하여 transaction을 수행하는 DApp을 실행합니다.

파트 1을 완료하면 Midnight 네트워크에 연결하고 Testnet blockchain 원장에 실제 변경을 기록하게 됩니다.

진행 중 문제가 발생하면 [getting help](/docs/develop/getting-help.mdx) 섹션에 안내된 경로를 통해 도움을 요청하세요.

# Prerequisites

## Supported platforms

이 안내는 최신 버전의 macOS 및 다양한 Linux 배포판에서 테스트되었습니다. Windows 환경에서는 Windows Subsystem for Linux(WSL)를 사용하여 테스트했으며, 구체적으로는
`Ubuntu 22.04.2 LTS (GNU/Linux 5.15.90.1-microsoft-standard-WSL2 x86_64)` 환경입니다.

## Docker

이 튜토리얼을 계속 진행하려면 Docker가 설치되어 있어야 합니다.
가장 쉽고 권장되는 설치 방법은 [Docker Desktop](https://docs.docker.com/desktop/)입니다.

Docker가 정상적으로 실행되는지 확인하세요. 아래 명령어를 shell 프롬프트에 입력하면 24.0.5와 같은 최신 버전 번호가 표시되어야 합니다.

```shell
docker --version
```

Midnight Docker 저장소에서 사용 가능한 이미지를 조회합니다.

```shell
docker search midnightnetwork
```

Docker Desktop에서 직접 이미지를 추가할 수도 있습니다.
