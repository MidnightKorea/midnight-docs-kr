# Use the Midnight Testnet

지금까지 다음을 준비했습니다:
- Lace 지갑
- 해당 지갑에 할당된 일정량의 tDUST
- 로컬에서 실행 중인 proof server

이제 Midnight Testnet에서 첫 번째 transaction을 수행할 준비가 되었습니다.

1. 친구의 수신 주소 또는 아래 주소를 복사하여 정확히 1.0 tDUST를 전송하세요.

```
mn_shield-addr_test1kjwksfp8x2tachehsfvufsdl35ljg5cxzdcysjdn6ntadspyxn3qxqrxypgjm055c2azrpuyn7un0ge2vm25vkfv38d24rj3ewcku5wmdc94gjr9
```

:::note Address Format Reminder
위 예시 주소는 레거시 HEX 형식입니다. Lace 지갑에서 수신 주소를 복사하면 기본적으로 Bech32m 형식으로 표시됩니다. 예: `mn_shield-addr_test1kjwksfp8x2tachehsfvufsdl35ljg5cxzdcysjdn6ntadspyxn3qxqrxypgjm055c2azrpuyn7un0ge2vm25vkfv38d24rj3ewcku5wmdc94gjr9`
:::



첫 번째 Midnight Testnet transaction을 완료했습니다. 이제 DApp을 만들어 봅시다!
