# About DUST

:::caution

Midnight 네트워크는 보안과 자산 보호를 최우선으로 하며, 여기에는 사기로부터의 안전도 포함됩니다. 현재 유통 중인 Midnight 토큰은 없음을 확인합니다.

토큰에 대한 향후 계획은 공식 채널을 통해 곧 안내드리겠습니다.

:::

Midnight은 blockchain 플랫폼이므로 고유 토큰이 있습니다. DUST는 Midnight에서 transaction을 처리하고 transaction 수수료를 지불하는 데 사용되는 토큰입니다. DUST를 통해 사용자는 Midnight 기반 DApp과 상호작용하며 다양한 [use case](../use-cases/)에서 여러 서비스 비용을 지불할 수 있습니다.

## Test DUST (tDUST)

Midnight은 현재 Testnet에서 운영되고 있으며, 이는 개발자가 초기에 접근할 수 있는 격리된 환경입니다. 따라서 사용자는 Testnet 내에서만 transaction 송수신 과정을 테스트할 수 있습니다.

Test DUST(tDUST)는 DUST의 Testnet 버전으로, Midnight Testnet 테스트 전용 토큰입니다.
