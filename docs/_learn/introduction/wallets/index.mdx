# Wallets

Midnight은 사용자가 Web3 wallet을 통해 DApp과 안전하게 상호작용하고 다른 사용자와 거래할 수 있도록 하는 것을 목표로 합니다. Web3 wallet은 탈중앙화 생태계에서 디지털 자산과 상호작용을 관리하는 보안 인터페이스 역할을 하는 핵심 도구입니다.

실물 wallet이 지폐와 동전을 보관하듯이, 디지털 wallet은 private key를 안전하게 저장합니다. Private key는 탈중앙화 네트워크에서 사용자의 자산과 권한에 대한 접근 권한을 부여하는 고유한 암호화 자격 증명입니다. 이 private key는 디지털 서명 역할을 하여 transaction을 인증하고 승인합니다.

예를 들어 설명하면:

- **Private key**는 디지털 신원과 자산에 대한 마스터 키와 같습니다. Private key를 잃으면 금고에 대한 접근 권한을 잃는 것과 같습니다.
- **Permission**은 wallet이 수행할 수 있는 작업을 제어하여, 자금 전송이나 계약 서명 같은 행위가 의도적이고 안전하게 이루어지도록 보장합니다.

Private key와 permission을 안전하게 관리함으로써 wallet은 사용자가 디지털 신원을 제어하고, 자산을 관리하며, DApp 및 기타 서비스와 안심하고 상호작용할 수 있도록 합니다. 이를 통해 개인은 향상된 보안과 프라이버시를 갖추고 탈중앙화 환경을 탐색할 수 있으며, Web3 상호작용이 직관적이고 안전해집니다.

## Where to store tDUST?

tDUST를 보관하려면 Midnight blockchain을 지원하는 wallet이 필요합니다. 이 wallet은 기기에 설치되는 애플리케이션으로, Midnight에서 transaction을 간편하게 송수신할 수 있습니다. 이 wallet은 기업과 개인 모두에게 적합합니다.

## Midnight Lace wallet
Midnight Testnet 단계에서 개발자와 사용자는 Midnight 전용 Lace(알파) 버전을 사용할 수 있습니다.
[Lace](https://www.lace.io/)는 Input Output Global(IOG)이 개발한 Web3 라이트 wallet 플랫폼입니다.

Lace는 Midnight 디지털 자산에 접근하고 관리하며, DApp과 상호작용하고, 개인 데이터에 대한 통제를 유지하기 위한 관문입니다.
