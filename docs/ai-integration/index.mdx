# AI integration

AI 코딩 어시스턴트는 빠르지만 Midnight에서는 환각을 일으킵니다. Compact과 Midnight SDK는 학습 데이터에 거의 포함되어 있지 않아, 혼자 두면 어시스턴트가 없는 문법을 지어내고 존재하지 않는 함수를 호출하며 컴파일 단계에서 실패하는 코드를 내놓습니다.

이 섹션에서는 그 간극을 메우는 도구들을 다룹니다. 방향을 정하고 승인하는 주도권은 여러분에게 두면서, 어시스턴트는 자신의 출력을 실제 Compact 컴파일러·SDK·소스에 대조 검증합니다. 지어낸 코드를 디버깅하는 시간은 줄고, 실제로 만드는 시간은 늘어납니다.

## What you can do

- 실제 컴파일러로 검증하여, 환각 문법 없이 Compact 스마트 컨트랙트를 작성합니다.
- DApp 프런트엔드를 스캐폴딩하고 컨트랙트 및 Lace wallet과 연결합니다.
- 로컬 devnet(노드, indexer, proof server)을 띄우고 상태를 점검합니다.
- push하기 전에 프라이버시 누출이 없는지 자신의 컨트랙트를 직접 리뷰합니다.
