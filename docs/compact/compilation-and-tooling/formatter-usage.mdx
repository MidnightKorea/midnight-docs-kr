# Compact 포매터 사용법

**format-compact** 도구의 사용법 페이지입니다.
이 문서는 **format-compact**을 단독으로 사용하는 경우를 기준으로 합니다.
다만, 포매터를 단독으로 사용하기보다는 Compact 커맨드라인 도구를 통해 사용하는 것을 권장합니다. [Compact 커맨드라인 도구 사용법](dev-tool-usage)은 별도 페이지에서 확인하세요.

NAME
====

format-compact

OVERVIEW
========

Compact 포매터는 Compact 툴체인의 일부로, 지정된 소스 파일의 Compact 소스 프로그램을 입력으로 받아 포매팅한 뒤, 지정된 파일에 결과를 기록합니다. 출력 파일이 지정되지 않으면 포매팅된 프로그램을 표준 출력에 출력합니다.

SYNOPSIS
========

**format-compact** _flag_ **...** _sourcepath_ _targetpath_
 
DESCRIPTION
===========

플래그 _flag_ **...**는 선택 사항이며, 아래 FLAGS 섹션에서 설명합니다.

_sourcepath_는 Compact 소스 프로그램이 담긴 파일을 지정하고, _targetpath_는 포매팅된 프로그램을 기록할 대상 파일을 지정합니다. _targetpath_가 기존 파일이면 포매팅된 프로그램으로 대체됩니다. _targetpath_를 _sourcepath_와 같게 설정하면 소스 프로그램이 포매팅된 결과로 대체됩니다.

FLAGS
=====

아래 플래그를 지정하면 포매터의 동작이 다음과 같이 변경됩니다:
 
**--help**

도움말을 출력한 뒤 종료합니다.

**--version**

컴파일러 버전을 출력한 뒤 종료합니다.

**--language-version**

언어 버전을 출력한 뒤 종료합니다.

**--vscode**

오류 메시지를 한 줄로 출력하여 Compact VS Code 확장에서 올바르게 표시되도록 합니다.

**--line-length _n_** 

목표 줄 길이를 _n_으로 설정합니다(기본값 100).

EXAMPLES
========

`src/test.compact`에 올바른 Compact 프로그램이 있다고 가정하고, 다음을 실행하면:

```bash
format-compact src/test.compact
```

**src/test.compact**의 포매팅된 프로그램을 표준 출력에 출력합니다.

**formatted**가 기존 디렉토리라고 가정하고, 다음을 실행하면:

```bash
format-compact src/test.compact formatted/test.compact
```

포매팅된 프로그램을 **formatted/test.compact**에 기록합니다. **formatted** 디렉토리가 없으면 포매터가 출력 파일을 생성할 수 없다는 오류를 출력합니다.

다른 방법으로, 다음을 실행하면:

```bash
format-compact src/test.compact src/test.compact
```

포매팅된 프로그램을 **src/test.compact**에 덮어씁니다.

**src/test.compact**에 잘못된 Compact 프로그램이 있는 경우, 다음을 실행하면:

```bash
format-compact src/test.compact
```

**src/test.compact**의 Compact 프로그램이 컴파일되지 못하는 원인을 설명하는 오류 메시지와 함께 종료됩니다.
