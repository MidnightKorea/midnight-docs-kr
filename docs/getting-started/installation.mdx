Midnight DApp 개발에 필요한 핵심 도구를 설치하는 방법을 안내합니다.

## Prerequisites

시작하기 전에 다음을 준비하세요:

- Google Chrome 브라우저
- Visual Studio Code
- Docker Desktop: [https://www.docker.com/products/docker-desktop/](https://www.docker.com/products/docker-desktop/)


개발은 Linux와 Mac에서 지원됩니다. 현재 Windows는 네이티브로 지원되지 않으므로, Windows 사용자는 WSL을 통한 개발을 권장합니다.

## Install Compact

[Compact](https://github.com/midnightntwrk/compact)는 애플리케이션의 데이터 보호 수준을 개발자가 직접 제어하도록 설계된 Midnight 전용 스마트 컨트랙트 언어입니다.

사전 빌드된 바이너리를 설치하세요:

```bash
curl --proto '=https' --tlsv1.2 -LsSf https://github.com/midnightntwrk/compact/releases/latest/download/compact-installer.sh | sh
```

### Update your shell PATH

설치 스크립트가 Compact를 셸 `PATH`에 자동으로 추가합니다. 단, 변경 사항을 적용하려면 터미널을 재시작하거나 셸 설정을 다시 로드해야 합니다.

터미널을 재시작하지 않고 셸 설정을 다시 로드하려면 다음을 실행하세요:

```bash
source ~/.zshrc # zsh의 경우
# 또는
source ~/.bashrc # bash의 경우
```

**수동 PATH 구성** (필요한 경우에만): 재시작 후에도 Compact를 찾을 수 없으면 수동으로 PATH에 추가하세요:

```bash
export PATH="$HOME/.local/bin:$PATH"
```

그런 다음 위와 같이 셸 설정을 다시 로드하세요.

### Update the compiler version

[호환성 매트릭스](../relnotes/support-matrix)에서 대상 네트워크에 해당하는 toolchain 버전을 설치하세요. 예를 들면 다음과 같습니다:

```bash
compact update 0.31.1
```

버전은 매트릭스에 나온 값으로 바꾸세요. 이 명령어는 해당 버전의 Compact 컴파일러를 다운로드하고 기본 버전으로 설정합니다. 버전 없이 `compact update`만 실행하면 가장 최근에 배포된 릴리스가 설치되는데, 이는 공개 네트워크에 아직 배포되지 않은 ledger 버전을 대상으로 할 수 있습니다. 따라서 사전 릴리스 네트워크를 대상으로 작업하는 경우가 아니라면 버전을 명시적으로 고정하세요.

### Verify the Compact installation

설치가 정상적으로 되었는지 확인하세요:

```bash
compact --version # Compact 버전 출력
compact compile --version # 컴파일러 버전 출력
which compact     # 설치 경로 출력
```

**확인**: 각 명령어가 Compact 버전 번호, 컴파일러 버전 번호, 설치 경로를 출력하면 정상입니다.

## Set up the proof server {#set-up-the-proof-server}

Proof server는 트랜잭션에 대한 영지식 증명을 로컬에서 생성합니다. 아래 절차에 따라 proof server를 실행하세요.

### Docker Desktop

Proof server는 Docker 기반 백그라운드 서비스로 실행됩니다. 다음 단계를 진행하기 전에 Docker 엔진이 실행 중인지 확인하세요.

### Run the proof server {#run-the-proof-server}

터미널에서 proof server를 시작하세요:

```bash
docker run -p 6300:6300 -e MIDNIGHT_PROOF_SERVER_VERBOSE=true midnightntwrk/proof-server:8.1.3
```

이 명령어는 실행 중인 동안 터미널을 점유합니다. `MIDNIGHT_PROOF_SERVER_VERBOSE=true` 설정은 디버그 로그를 켜는데, proof server가 요청을 거부할 때 그 이유를 보여줍니다.

**확인**: `http://localhost:6300`에서 수신 대기 중이라는 로그가 터미널에 표시되면 정상입니다.

:::note
로컬 proof server를 Lace Midnight wallet과 함께 사용하려면, **Settings » Midnight**으로 이동하여 `Local (http://localhost:6300)`을 선택하세요. 현재 Lace에서는 로컬 proof server만 지원됩니다.
:::

## Install the Compact VS Code extension

Compact VS Code 확장 프로그램은 구문 강조와 코드 스니펫 자동 완성을 지원합니다. 다음 단계에 따라 설치하세요:

<StepsProvider>
    <Step>[VSIX 패키지](https://raw.githubusercontent.com/midnight-ntwrk/releases/gh-pages/artifacts/vscode-extension/compact-0.2.13/compact-0.2.13.vsix)를 다운로드하세요.</Step>
    <Step>VS Code에서 **Extensions**로 이동한 다음 **Install from VSIX**를 선택하고 확장 프로그램 파일을 선택하세요.</Step>
</StepsProvider>

**확인**: VS Code의 설치된 확장 프로그램 목록에 Compact Language Support가 나타나면 정상입니다.

## Install Complete

개발 환경 구성이 완료되었습니다. 이제 Midnight에서 프라이버시 기반 애플리케이션을 빌드할 수 있습니다.

Midnight DApp을 배포하고 사용하려면 Midnight Node와 Indexer가 모두 필요합니다. 이들은 RPC endpoint로 제공되며 [최신 안정 릴리스](https://docs.midnight.network/relnotes/overview#environments)에서 확인할 수 있습니다. 이후 튜토리얼에서 사용법을 다루며, [예제](/examples) 섹션에서 전체 DApp 데모를 확인할 수 있습니다.

## Troubleshoot

셸이 `compact` 명령어를 찾지 못하거나, Docker가 실행 중이 아니거나, 포트 6300이 이미 사용 중이라면 [Troubleshoot installation problems](../troubleshoot/installation-problems)를 참고하세요.
