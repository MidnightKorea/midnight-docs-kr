# Set up boot node

Boot node는 Midnight 네트워크에 합류하는 노드의 초기 연결 지점 역할을 합니다. 새 노드가 네트워크의 활성 피어를 찾아 연결하도록 돕습니다. Boot node 운영은 선택 사항이지만, 운영하면 네트워크 탈중앙화가 강화되고 피어 디스커버리가 개선됩니다.

이 가이드는 Midnight boot node를 설정하는 단계별 방법을 안내합니다.

## Prerequisites

Midnight boot node 설정 전에 다음 사항을 준비하세요:

* PostgreSQL 포트에 접근할 수 있는 [Cardano-db-sync 인스턴스 설정](./cardano-db-sync) 완료.
* 환경 변수가 설정된 [Midnight node 설정](./full-node#install-midnight-node) 완료.

## Set up a boot node

다음 명령어로 Midnight node를 boot node 모드로 실행합니다. 대상 네트워크에 맞는 설정을 선택하세요.

<Tabs>
<TabItem value="preview" label="Preview">
```bash
midnight-node \
  --chain /home/midnight/res/preview/chain-spec-raw.json \
  --base-path /home/midnight/data \
  --listen-addr /ip4/0.0.0.0/tcp/30333 \
  --bootnodes /dns/bootnode-1.preview.midnight.network/tcp/30333/ws/p2p/12D3KooWK66i7dtGVNSwDh9tTeqov1q6LSdWsRLJvTyzTCaywYgK \
  --no-private-ip
```
</TabItem>
<TabItem value="preprod" label="Preprod">

```bash
midnight-node \
  --chain /home/midnight/res/preprod/chain-spec-raw.json \
  --base-path /home/midnight/data \
  --listen-addr /ip4/0.0.0.0/tcp/30333 \
  --bootnodes /dns/bootnode-1.preprod.midnight.network/tcp/30333/ws/p2p/12D3KooWQxxUgq7ndPfAaCFNbAxtcKYxrAzTxDfRGNktF75SxdX5 \
  --no-private-ip
```

</TabItem>
</Tabs>
