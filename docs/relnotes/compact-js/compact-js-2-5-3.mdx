## High-level summary

Compact.js은 [Compact](../../compact) 언어로 컴파일된 스마트 컨트랙트용 TypeScript 기반 실행 환경을 제공합니다.

버전 2.5.3은 유지 보수 릴리스이며, 이전된 `midnightntwrk/midnight-sdk` 저장소에서 npm에 게시된 첫 버전입니다. 패키지의 CommonJS exports 설정을 수정하고, `tar` 의존성에 보안 업데이트를 적용하며, 개발 의존성과 릴리스 자동화를 갱신합니다.

버전 2.5.1과 2.5.2는 저장소 이전 과정에서의 버전 정렬 단계였습니다. 2.5.1은 GitHub 릴리스 없이 npm에 게시되었고, 2.5.2는 태그만 달리고 npm에는 게시되지 않았습니다. 버전 2.5.3이 이 둘을 모두 대체합니다.

---

## Audience

이번 릴리스는 Midnight 블록체인에서 컨트랙트를 배포하고 상호작용하는 도구나 프레임워크를 구축하는 개발자에게 해당됩니다.

---

## New features

이번 릴리스에는 새로운 기능이 없습니다.

---

## Improvements

- 패키지의 CommonJS exports 설정을 수정해, `require`를 사용하는 소비자가 패키지를 올바르게 해석하도록 했습니다.
- 보안 업데이트: `tar` 의존성을 7.5.16으로 올렸습니다.
- turbo, commitlint, `@effect` 패키지, 린트 도구를 포함한 개발 의존성을 갱신했습니다.
- 이전된 저장소의 버전 범프 및 릴리스 자동화를 수정했습니다.

---

## Deprecations

이번 릴리스에는 deprecation이 없습니다.

---

## Breaking changes

이번 릴리스에는 호환성을 깨는 변경이 없습니다.

---

## Important notes

GitHub 릴리스에 첨부된 changelog는 누적 방식으로 생성되며, circuit 실행에 대한 `LedgerParameters` 지원처럼 이전 2.5.x 버전에서 제공된 기능 항목을 반복합니다. 해당 변경 사항은 [2.5.0 릴리스 노트](/relnotes/compact-js/compact-js-2-5-0)를 참조하세요.
