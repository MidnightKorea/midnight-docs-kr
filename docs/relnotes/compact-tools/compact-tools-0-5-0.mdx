## Compact developer tools 0.5.0 release notes

Compact developer tools(devtools) 0.5.0은 두 가지 편의성 개선을 제공합니다. 이제 서브커맨드를 축약할 수 있고, `update` 서브커맨드가 부분 버전 번호를 받습니다.

기존 devtools 설치가 있다면 `compact self update` 명령으로 업데이트할 수 있습니다.

기존 devtools 설치가 없다면 [릴리스 페이지](https://github.com/midnightntwrk/compact/releases/tag/compact-v0.5.0)에 표시된 셸 명령으로 버전 0.5.0을 설치할 수 있습니다.

## New features

### Subcommand abbreviations

`compact` CLI가 이제 서브커맨드의 축약을 받습니다. 예를 들어 `update`는 `compact up`, `compile`은 `compact c`, `format`은 `compact fmt`로 쓸 수 있습니다.

대부분의 서브커맨드에는 공식 별칭이 있습니다. 예를 들어 `format`에는 `fmt`, `fixup`에는 `fx`가 있습니다. 이 별칭들은 `compact help`나 `compact --help`에서 볼 수 있는 도움말 텍스트에 나열되어 있습니다.

또한 대부분의 서브커맨드는 모호하지 않은 접두사를 받으므로 `compact c`, `compact co`, `compact com`이 모두 `compile`로 동작합니다. 접두사가 모호한 경우 도구가 하나를 선택합니다. `compact c`는 `clean`이 아니라 `compile`을 실행합니다.

GitHub 사용자 `rvcas`가 이 기능을 기여했습니다.

### Partial version numbers

`update` 서브커맨드가 이제 부분 버전 번호를 받습니다. 예를 들어 패치 번호를 생략한 `compact update 0.30`은 최신 0.30.x 툴체인으로 업데이트하므로, 가장 최신 버전을 받기 위해 패치 버전이 몇 개나 있는지 알 필요가 없습니다.

마찬가지로 `compact update 0`은 최신 0.x.y 버전으로 업데이트합니다. 이는 Compact 1.0 이후에 더 유용해지는데, 그때는 `compact up 1`로 Compact 1의 최신 패치 버전을 유지할 수 있습니다.

GitHub 사용자 `adamreynolds-io`가 이 기능의 일부를 기여했습니다.

## Breaking changes

없음.

## Known issues

- zkir 도구가 ARM Docker 환경에서 에뮬레이션으로 x64 바이너리를 실행하면 `SIGILL`로 크래시합니다. 이 릴리스에는 aarch64 Linux 빌드가 없기 때문입니다([issue #220](https://github.com/LFDT-Minokawa/compact/issues/220)). 네이티브 ARM64 Linux 바이너리를 추가한 [devtools 0.5.1](/relnotes/compact-tools/compact-tools-0-5-1)에서 수정되었습니다.
