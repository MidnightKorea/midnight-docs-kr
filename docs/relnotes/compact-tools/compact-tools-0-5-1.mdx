## Compact developer tools 0.5.1 release notes

Compact developer tools(devtools) 0.5.1은 네이티브 ARM64 Linux 사전 빌드 바이너리(`aarch64-unknown-linux-musl`)를 릴리스 아티팩트에 추가합니다. Apple Silicon 호스트의 컨테이너 같은 ARM Docker 환경에서 더 이상 x64 바이너리를 에뮬레이션할 필요가 없습니다. 에뮬레이션은 zkir 도구를 `SIGILL`로 크래시시켰습니다([issue #220](https://github.com/LFDT-Minokawa/compact/issues/220)).

이번 릴리스에서 CLI 자체의 기능 변경은 없습니다.

기존 devtools 설치가 있다면 `compact self update` 명령으로 업데이트할 수 있습니다.

기존 devtools 설치가 없다면 [릴리스 페이지](https://github.com/midnightntwrk/compact/releases/tag/compact-v0.5.1)에 표시된 셸 명령으로 버전 0.5.1을 설치할 수 있습니다.

## New features

### Native ARM64 Linux binaries

릴리스 아티팩트에 이제 기존의 Apple Silicon macOS, Intel macOS, x64 MUSL Linux 빌드와 함께 `aarch64-unknown-linux-musl` 빌드가 포함됩니다. 설치 스크립트가 플랫폼에 맞는 빌드를 자동으로 선택합니다.
