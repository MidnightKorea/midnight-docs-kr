## High-level summary

DApp Connector API v4.0.1은 v4.0.0 재설계에 대한 패치 릴리스입니다. 트랜잭션 메서드 타입의 빈틈을 메웁니다. 수수료 지급을 끄는 옵션이 `makeIntent`에서만 제공되었는데, 이번 릴리스는 같은 `payFees` 옵션을 모든 트랜잭션 메서드에 하위 호환 방식으로 추가합니다. 이제 모든 트랜잭션 메서드가 동일한 API를 공유합니다.

수수료 지급을 끄면 DApp이 수수료를 다른 곳에서 지급하는 트랜잭션을 구성할 수 있습니다. 예를 들어 별도의 전용 서비스에서 실행되는 스폰서 지갑이 수수료를 지급할 수 있습니다.

---

## Audience

다음에 해당하는 개발자에게 유용합니다:

- DApp에서 `@midnight-ntwrk/dapp-connector-api`를 사용하는 경우
- 연결된 지갑이 아닌 다른 지갑이 트랜잭션 수수료를 지급하는 스폰서 수수료 흐름을 만드는 경우
- DApp Connector API와 호환되는 지갑 구현을 유지보수하는 경우

---

## What changed (Summary of updates)

- `payFees` 옵션을 모든 트랜잭션 메서드에 추가했습니다. 이전에는 `makeIntent`에서만 제공했습니다.
- 이 옵션의 도입 배경을 API 명세에 문서화했습니다.

---

## New features

### `payFees` option on all transacting methods

이제 모든 트랜잭션 메서드가 `makeIntent`에 이미 있던 `payFees` 옵션을 받으므로, connector가 만드는 어떤 트랜잭션에서든 수수료 지급을 끌 수 있습니다. 이 변경은 하위 호환됩니다. 옵션을 생략하면 연결된 지갑에서 수수료를 지급하던 기존 동작이 유지됩니다.
