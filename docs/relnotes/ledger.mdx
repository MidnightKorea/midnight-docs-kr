# Ledger

Midnight ledger(Ledger)은 컨트랙트 상태와 토큰 상태를 기록하는 공개 저장소입니다. Zswap 암호학적 commitment와 컨트랙트 주소를 각 상태에 매핑합니다.

[관련 문서 링크](../../concepts/how-midnight-works/semantics)

## Component versions by release
