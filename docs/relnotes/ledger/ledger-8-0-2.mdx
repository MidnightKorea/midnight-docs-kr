## High-level summary

Ledger 8.0.2는 Merkle tree canonicity와 등록 중의 DUST change 계산에 대한 수정을 도입합니다. 또한 ledger state용 `with_genesis_settings` 생성자, 네이티브 Arm proof server 빌드, 마지막 블록 타임 context 변수 같은 새 기능이 추가되었습니다.

이번 릴리스에는 로깅, sequencing 검사 반복 결정성, `dust.rs`의 0 나눗셈 처리(panic에서 error로 변경)에 대한 버그 수정도 포함되어 있습니다.

## Audience

이번 릴리스 노트는 Ledger WASM 바인딩을 사용하여 애플리케이션을 구축하는 개발자에게 해당됩니다.

---

## What changed (Summary of updates)

이번 릴리스는 동작 수준의 수정과 개발자 대상 개선을 함께 포함합니다. 아래 업데이트는 결정성과 트랜잭션 정확성을 향상시키는 수정 사항을 강조합니다.

- 등록 중에 지출되는 DUST의 change 계산 수정 (동작 수준 breaking change)
- Merkle tree canonicity 수정 (동작 수준 breaking change)
- 마지막 블록 타임 context 변수 추가
- 초기 파라미터와 풀 할당을 위한 ledger state 생성자 `with_genesis_settings` 추가
- 네이티브 Arm proof server 빌드 지원 추가
- proof-erased가 아닌 트랜잭션 해시 로깅
- sequencing 검사의 비결정성과 사양 외 반복 순서 문제 해결
- 일부 코드 경로에서 전체 ledger state가 구조화 로깅에 의도치 않게 포함되던 문제 제거
- `dust.rs`의 0 나눗셈을 panic에서 error로 변경

## New features

이번 릴리스에 도입된 새로운 기능은 다음과 같습니다.

### 마지막 블록 타임 context 변수

`blockContext`가 이제 `lastBlockTime`을 노출합니다.

### `LedgerState::with_genesis_settings` 생성자

이 생성자는 네트워크 ID, 초기 파라미터, 시스템 관리 풀 등 명시적 genesis 파라미터로 새 ledger state를 생성합니다.

- locked 풀: Midnight에 락(lock) 상태로 있으면서 Cardano에서 cNIGHT로 유통되는 자금
- reserve 풀: 프로토콜 참여 보상용으로 할당된 자금
- treasury 풀: 거버넌스가 통제하는 전략적 용도용 자금

## Breaking changes

개발자가 알아둬야 할 breaking change와 필요한 조치는 다음과 같습니다.

### 마지막 블록 타임 context 변수

`blockContext`에 `lastBlockTime` 필드가 추가되었습니다.

**필요한 조치**: 없음

### 트랜잭션 동작 변경

이번 릴리스에는 Merkle tree canonicity 수정, DUST 등록 change 계산 수정 등, API 시그니처 변경 없이 동작 수준에서 발생하는 breaking change가 포함됩니다.

**필요한 조치**: 없음
