## High-level summary

Ledger 8.1.1은 8.1.0에 대한 패치 릴리스입니다. 배열 처리에 대한 테스트 커버리지를 추가하고, clippy 1.97 lint 정리와 함께 현재의 ledger-8 CI 및 릴리스 자동화를 포함합니다. well-formed 트랜잭션에 대한 프로토콜, 직렬화, API 동작 변경은 없습니다.

개발자가 조치해야 할 사항은 npm 스코프 변경 하나입니다. ledger 패키지는 이제 `@midnight-ntwrk` 대신 `@midnightntwrk` 스코프로 배포됩니다.

## Audience

이번 릴리스 노트는 다음 개발자에게 가장 관련이 깊습니다.

- 노드 개발자
- ledger WASM 바인딩을 사용하는 개발자

## Summary of updates

- 배열 처리에 대한 테스트 커버리지 추가
- 워크스페이스 전반의 clippy 1.97 `useless_borrows_in_formatting` lint 정리. `base-crypto`의 `AlignedValue` 포맷 인자 포함
- ledger-8 CI 및 릴리스 자동화 업데이트

## Breaking changes or required actions

### npm packages move to the `@midnightntwrk` scope

npm 패키지는 이제 기존 `@midnight-ntwrk` 대신 `@midnightntwrk` 스코프로 배포됩니다. `package.json`의 의존성을 이에 맞춰 수정하세요. 예를 들어 `@midnight-ntwrk/ledger-v8`은 `@midnightntwrk/ledger-v8`이 됩니다. API 변경은 없으며 패키지 이름만 바뀝니다.
