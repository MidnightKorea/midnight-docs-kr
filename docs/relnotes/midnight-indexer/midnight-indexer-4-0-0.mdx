* **Version**: v4.0.0
* **Date**: 2026-03-17

---

## High-level summary

이번 릴리스는 Indexer API를 v4로 업그레이드하고 노드 0.22와 Ledger 8에 대한 지원을 추가합니다. 성능, 안정성, 내부 스토리지 업데이트도 포함되어 있습니다.

호환성을 위해 `/api/v3`는 현재 `/api/v4`의 별칭으로 사용할 수 있지만, 타깃 API 버전은 v4로 간주해야 합니다.

---

## Audience

이번 릴리스 노트는 다음 개발자에게 해당됩니다.

- Indexer API를 통해 Midnight Indexer를 사용하는 개발자
- Midnight Indexer를 운영·배포하는 개발자

---

## What changed (Summary of updates)

아래 업데이트는 클라이언트 통합 담당자와 Indexer 운영자를 위한 핵심 변경 사항을 요약합니다.

- Indexer API를 v3에서 v4로 업그레이드
- 단기 하위 호환성을 위해 `/api/v3`를 `/api/v4`의 별칭으로 추가
- 노드 0.22와 Ledger 8에 대한 지원 추가
- 결정론적 세션 ID를 세션마다 생성되는 랜덤 토큰(`indexer-api`)으로 교체
- `storage-core` v1.1 (layout v2)으로 업데이트
- ledger 이벤트 쿼리 경로에서 윈도우 함수를 스칼라 서브쿼리로 교체
- SQL 왕복 횟수를 줄이기 위해 `ledger_db_nodes` 삽입을 배치 처리
- 재귀 깊이 제한 문제를 방지하기 위해 ledger 상태 역직렬화에 지연 로딩 도입

---

## New features

이번 릴리스에서 도입된 새로운 기능은 다음과 같습니다.

### Indexer API v4

Indexer API가 이제 v4입니다. 모든 신규 통합에 권장되는 API 버전입니다.

### v3 임시 호환성 별칭

`/api/v3`가 `/api/v4`의 별칭으로 제공되어, 기존 클라이언트의 마이그레이션 기간을 지원합니다.

---

## Improvements

- 결정론적 세션 ID를 세션마다 생성되는 랜덤 토큰(`indexer-api`)으로 교체
- SQL 왕복 횟수를 줄이기 위해 `ledger_db_nodes` 삽입을 배치 처리
- ledger 이벤트 쿼리 로직에서 윈도우 함수를 스칼라 서브쿼리로 교체
- 재귀 깊이 제한을 피하기 위해 ledger 상태 역직렬화에 지연 로딩 도입

---

## Breaking changes

개발자가 알아둬야 할 breaking change와 필요한 조치는 다음과 같습니다.

### API 버전 v4로 업데이트

**변경 내용**: 주 Indexer API 버전이 v4가 되었습니다.

**영향**: 구 API 가정에 고정된 클라이언트는 v4 스키마와 동작에 맞지 않으면 실패할 수 있습니다.

**필요한 조치**: 클라이언트를 API v4로 업데이트하고 스키마 호환성을 검증하세요. `/api/v3`는 과도기용으로 취급하세요.

### 내부 데이터베이스 스토리지 포맷 업데이트

**변경 내용**: 내부 데이터베이스 포맷이 `storage-core` v1.1 (layout v2)으로 이동했습니다.

**영향**: 이전 레이아웃 버전의 기존 데이터베이스 상태는 그대로 재사용할 수 없습니다.

**필요한 조치**: 이번 릴리스를 배포할 때는 새로운 또는 빈 데이터베이스에서 시작하세요.
