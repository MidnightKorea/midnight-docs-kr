* **Version**: v4.0.2
* **Date**: April 23, 2026
* **Paired node**: 0.22.x
* **API version**: v4

---

## High-level summary

Midnight Indexer 4.0.2는 4.0.x 유지보수 라인의 패치 릴리스로, 트랜잭션 수수료(`paidFees`) 계산 방식을 바로잡습니다. 4.1.0에서 개발 라인에 반영된 수정을 백포트한 것입니다. 이 수정은 이미 인덱싱된 데이터의 수수료를 다시 계산하므로, 업그레이드하려면 초기화와 재인덱싱이 필요합니다.

:::caution[4.0.1에서 업그레이드]
4.0.2로 업그레이드할 때는 indexer를 초기화하고 genesis부터 재인덱싱하세요. Mainnet 또는 Preprod 규모에서는 약 3~4일을 예상하세요.
:::

---

## Audience

이번 릴리스 노트는 다음 대상에게 해당됩니다.

- 노드 0.22.x에 맞춰 Midnight Indexer 4.0.x를 운영하는 운영자
- Indexer API에서 트랜잭션 수수료 값을 읽는 개발자

---

## What changed

- `paidFees` 계산 수정 — [#1031](https://github.com/midnightntwrk/midnight-indexer/pull/1031)과 [#1061](https://github.com/midnightntwrk/midnight-indexer/pull/1061)의 백포트 ([#1068](https://github.com/midnightntwrk/midnight-indexer/pull/1068))

---

## Breaking changes

GraphQL 스키마 변경은 없습니다. 위의 재인덱싱 요구 사항은 운영상의 사항이며 API 변경이 아닙니다.

---

## Bug fixes

### `paidFees` computation

이제 트랜잭션 수수료를 ledger 자체 fee API로 계산하므로, indexer가 반환하는 `paidFees` 값이 노드가 부과한 값과 일치합니다. 기존 인덱스 상태에는 이전 값이 남아 있어 재인덱싱이 필요합니다. ([#1068](https://github.com/midnightntwrk/midnight-indexer/pull/1068))
