* **Version**: v4.3.1
* **Date**: May 11, 2026
* **Paired node**: 1.0.0 (0.22.x also supported)
* **Paired ledger**: 8.1

---

## High-level summary

Midnight Indexer 4.3.1은 4.3.x 라인의 패치 릴리스입니다. dust 및 shielded nullifier 구독 응답 타입에 `transactionHash` 필드를 추가하는 additive 변경으로, 지갑이 추가 조회 없이 구독 이벤트와 트랜잭션을 연결할 수 있습니다. 또한 남아 있던 프로덕션 panic 경로를 error 반환으로 교체합니다.

노드 0.22.x를 사용하는 운영자는 4.0.x 유지보수 라인에 머물러야 합니다.

---

## Audience

이번 릴리스 노트는 다음 대상에게 해당됩니다.

- 노드 1.0.0 이상에 맞춰 Midnight Indexer를 운영하는 운영자
- `dustGenerations`, `dustNullifierTransactions`, `shieldedNullifierTransactions` 구독을 사용하는 지갑 통합 담당자

---

## What changed

- `DustGenerationsItem`, `DustNullifierTransaction`, `ShieldedNullifierTransaction`에 `transactionHash: HexEncoded!` 필드 추가 ([#1116](https://github.com/midnightntwrk/midnight-indexer/pull/1116))
- 남아 있던 프로덕션 panic을 error 반환으로 교체 ([#1105](https://github.com/midnightntwrk/midnight-indexer/pull/1105))

---

## New features

### `transactionHash` on subscription response types

세 가지 nullifier·generation 구독 타입이 각 항목이 속한 트랜잭션의 hash를 담습니다. 이 값은 스키마의 다른 곳에 있는 `Transaction.hash`와 일치하므로, 지갑이 이벤트와 해당 트랜잭션을 바로 연결할 수 있습니다.

---

## Breaking changes

없습니다. 4.3.0에서 그대로 업그레이드할 수 있습니다.

---

## Bug fixes

### Production panics replaced with error returns

예기치 않은 상태 형태가 이제 프로세스를 종료시키는 대신 일반적인 error 경로를 통해 드러납니다. ([#1105](https://github.com/midnightntwrk/midnight-indexer/pull/1105))
