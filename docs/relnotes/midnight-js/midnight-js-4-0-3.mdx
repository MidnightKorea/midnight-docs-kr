## High-level summary

이번 릴리스에서는 새 패키지 두 개를 추가합니다. barrel 패키지는 Midnight.js 핵심 모듈을 하나의 import 지점으로 모아 줍니다. proof provider는 독립 proof server 대신 연결된 지갑에 증명을 위임합니다. 또한 `testkit-js`의 안정성을 폭넓게 개선했습니다.

v4.0.3 퍼블리시는 완료되지 못했습니다. 메인테이너는 v4.0.4 노트에서 v4.0.3이 "릴리스 파이프라인 문제로 퍼블리시되지 않았다"고 기록했고, v4.0.4가 v4.0.3의 모든 변경을 포함한다고 밝혔습니다. npm에는 새 패키지 두 개만 4.0.3 버전으로 올라가 있으며, 각 패키지는 파이프라인이 끝내 퍼블리시하지 않은 4.0.3 버전에 내부 의존성을 고정해 두고 있습니다. 그래서 두 패키지 모두 설치되지 않습니다. 이 문서에서 설명하는 내용을 받으려면 [v4.0.4](/relnotes/midnight-js/midnight-js-4-0-4) 이상을 사용하세요.

## Audience

다음에 해당하는 개발자에게 특히 중요합니다:

- Midnight.js 핵심 패키지를 각각 import하는 대신 하나의 import 지점으로 가져오고 싶은 경우
- 브라우저 DApp을 개발하면서 proof server를 직접 운영하는 대신 연결된 지갑이 증명을 생성하길 원하는 경우
- `testkit-js`로 통합 테스트를 작성하며 그 assertion, 오류 전파, 환경 변수 처리에 의존하는 경우
- Midnight.js 버전 이력을 추적하면서 npm 레지스트리가 왜 4.0.2에서 4.0.4로 건너뛰는지 알아야 하는 경우

## Summary of updates

- `@midnight-ntwrk/midnight-js` barrel 패키지를 추가했습니다.
- `@midnight-ntwrk/midnight-js-dapp-connector-proof-provider` 패키지를 추가했습니다.
- `testkit-js`에서 누락된 assertion, 삼켜진 오류, 오래된 환경 변수와 관련된 버그 15건을 수정했습니다.
- issue 720에서 보고된 `sendUnshielded` 실패를 재현하는 테스트를 추가했습니다.
- 개발 의존성 업데이트를 하나로 통합했습니다.
- 생성된 API 문서를 갱신했습니다.

## New features

### `@midnight-ntwrk/midnight-js` barrel package

이 패키지는 Midnight.js 핵심 패키지들을 네임스페이스로 다시 export하므로, 의존성 하나로 가져올 수 있습니다. barrel은 provider 패키지와 Compact CLI 도구를 의도적으로 제외합니다. 덕분에 패키지가 가벼워지고, 환경에 종속적인 HTTP·파일시스템 의존성을 끌어들이지 않습니다.

네임스페이스 import:

```typescript
import { contracts, networkId, types, utils } from '@midnight-ntwrk/midnight-js';

networkId.setNetworkId('preprod');
const deployed = await contracts.deployContract(/* ... */);
```

서브패스 import:

```typescript
import { deployContract } from '@midnight-ntwrk/midnight-js/contracts';
import { setNetworkId } from '@midnight-ntwrk/midnight-js/network-id';
```

다시 export하는 네임스페이스:

- `@midnight-ntwrk/midnight-js-contracts`의 `contracts`
- `@midnight-ntwrk/midnight-js-network-id`의 `networkId`
- `@midnight-ntwrk/midnight-js-types`의 `types`
- `@midnight-ntwrk/midnight-js-utils`의 `utils`

패키지 이름을 비우기 위해 리포지터리 루트 워크스페이스가 `@midnight-ntwrk/midnight-js-monorepo`라는 이름을 가져갔습니다. 이는 리포지터리에서 작업하는 기여자에게 영향을 주며, 퍼블리시된 패키지를 사용하는 쪽에는 영향이 없습니다.

### `@midnight-ntwrk/midnight-js-dapp-connector-proof-provider` package

이 패키지는 DApp Connector의 `getProvingProvider` API를 Midnight.js `ProofProvider` 인터페이스로 감쌉니다. 그러면 연결된 지갑이 증명을 생성하므로, DApp에 자체 proof server가 필요하지 않습니다.

```typescript
import { dappConnectorProofProvider } from '@midnight-ntwrk/midnight-js-dapp-connector-proof-provider';

const proofProvider = await dappConnectorProofProvider(
  walletConnectedAPI,
  zkConfigProvider,
  costModel
);
```

다음을 export합니다:

- `dappConnectorProofProvider`는 DApp Connector 지갑 API로부터 완전한 `ProofProvider`를 만듭니다.
- `dappConnectorProvingProvider`는 더 낮은 수준의 `ProvingProvider`만 만듭니다.
- `DAppConnectorProvingAPI`는 `Pick<WalletConnectedAPI, 'getProvingProvider'>`의 타입 별칭입니다. `@midnight-ntwrk/dapp-connector-api`의 `WalletConnectedAPI` 타입을 기반으로 하므로, 그 타입의 변경을 그대로 따라갑니다.

## Bug fixes and quality improvements

### Testkit-js reliability fixes

이번 릴리스는 `testkit-js`의 버그와 설계 문제 15건을 수정합니다:

- `expectSuccessfulDeployTx`와 `expectSuccessfulCallTx`가 matcher 없이 `expect()`를 호출해 아무것도 검증하지 않았습니다.
- `ledgerStateBlob`과 `ledgerVersion`이 RPC 호출에서 `blockHash` 파라미터를 무시했습니다.
- `waitForFunds`가 `bigint` 또는 지갑 상태 객체를 반환하곤 했습니다. 이제는 항상 `bigint`를 반환합니다.
- `BigInt.prototype.toJSON`이 `Number(this)`를 사용해 큰 값에서 정밀도를 잃었습니다. 이제는 `toString()`을 사용합니다.
- `FaucetClient.requestTokens`, `ProofServerClient.proveTx`, 모든 `health()` 메서드, `WalletSaveStateProvider.save`가 오류를 전파하지 않고 잡아서 로그로만 남겼습니다. 이제는 오류를 전파합니다.
- `health()` 메서드들이 설정된 URL에서 프로토콜을 가져오지 않고 `https://` 또는 `http://`를 하드코딩했습니다. 이제는 `buildUrlWithPath` 헬퍼가 이를 처리합니다.
- `MN_TEST_INDEXER` 같은 모듈 수준 상수가 import 시점에 환경 변수를 캡처했습니다. 이를 getter 함수로 대체해, 이제는 import 이후에 설정한 값을 읽습니다.
- 테스트가 `process.env`를 복원하지 않고 변경했습니다. 이제는 `afterEach` 정리 단계에서 이를 초기화합니다.
- `WalletSaveStateProvider.save`가 `.replaceAll('.gz', '')`를 사용해, 경로 다른 위치에 그 문자열이 있으면 경로가 손상될 수 있었습니다. 이제는 `.endsWith('.gz')`로 확인한 뒤 잘라냅니다.
- `FluentWalletBuilder.build()`가 빌더 내부의 `seeds` 상태를 변경했습니다. 이제는 지역 상수를 사용합니다.
- `TestEnvironment`에서 사용하지 않던 `envConfiguration` 필드를 제거했습니다.
- `deleteDirectory`를 `tryDeleteDirectory`로 바꿔, 오류를 삼키는 동작을 이름에서 분명히 드러냈습니다.

### Additional test coverage

이번 릴리스는 [issue 720](https://github.com/midnightntwrk/midnight-js/issues/720)을 재현하는 단위 테스트를 추가합니다. 이 이슈는 대상 사용자 주소가 지갑 자체 주소와 다를 때 `sendUnshielded`가 실패하는 문제입니다. 테스트는 이 동작을 포착할 뿐, 동작을 바꾸지는 않습니다.

### Development dependency updates

변경 하나로 ESLint, jsdom, Turbo, TypeDoc, Allure, GitHub Actions 두 건을 아우르는 미처리 의존성 업데이트 PR 여덟 건을 통합했습니다. 모두 개발 의존성이므로, 퍼블리시된 패키지의 동작은 바뀌지 않습니다.

## Known issues

v4.0.3 npm 퍼블리시는 불완전합니다. npm에는 `@midnight-ntwrk/midnight-js`와 `@midnight-ntwrk/midnight-js-dapp-connector-proof-provider`에 대해서만 4.0.3 버전이 올라가 있습니다. 4.0.2에 이미 존재하던 패키지는 모두 곧바로 4.0.4로 넘어갔습니다. 두 4.0.3 패키지는 레지스트리에 없는 4.0.3 버전에 정확히 일치하는 의존성을 선언하므로, 둘 중 어느 쪽을 설치해도 의존성 해석에 실패합니다.

대신 v4.0.4 이상을 설치하세요. 이 페이지에 나열된 모든 변경을 포함합니다.
