## High-level summary

Node v1.0.1은 [v1.0.0 GA 라인](/relnotes/node/node-1-0-0)의 패치 릴리스입니다. `unsafe_allow_symlinks` 설정 필드에 기본값을 부여하여, TOML 설정 파일 없이 실행하는 노드가 필드 누락 오류로 부팅에 실패하던 v1.0.0의 known issue를 해결합니다. 또한 이번 릴리스는 Preview 네트워크의 genesis와 chain spec을 재생성하고, Preview reserve 설정을 바로잡으며, ledger 버전 범프와 의존성 업데이트를 백포트합니다.

런타임은 1.0.0에 머무르므로 운영자는 노드 바이너리만 업데이트하면 됩니다.

GitHub 릴리스에 첨부된 changelog는 누적이라서 이미 v1.0.0에 포함된 변경 사항을 다시 나열합니다. 아래에 나열한 변경 사항은 v1.0.0 대비 델타입니다.

---

## Audience

이 릴리스 노트는 다음에 해당하는 사용자에게 유효합니다.

- TOML 설정 파일 없이 Midnight node 인프라를 운영하다가 v1.0.0에서 `missing field unsafe_allow_symlinks` 부팅 오류를 만난 사용자
- Preview 네트워크 노드를 운영하는 사용자. 재생성된 genesis, chain spec, 바로잡은 reserve 설정이 반영됩니다.

DApp 개발자와 toolkit 사용자는 이번 릴리스에 대해 별도 조치가 필요 없습니다.

---

## What changed (Summary of updates)

아래 업데이트는 이번 릴리스의 주요 변경 사항입니다.

- `unsafe_allow_symlinks`에 기본값을 부여하여, TOML 설정 파일 없이 실행하는 노드가 값을 명시하지 않아도 부팅되도록 했습니다.
- Preview 네트워크의 genesis와 chain spec을 재생성했습니다.
- Preview reserve 설정에서 잘못된 `NIGHT` asset 이름을 제거했습니다. 이제 `asset_name` 필드는 비어 있으며, 이미 `main`에 적용된 수정과 일치합니다.
- ledger 버전 범프를 릴리스 브랜치에 백포트했습니다.
- 릴리스 빌드를 수정하기 위해 의존성을 업데이트했습니다.

## Bug fixes and quality improvements

### Default for `unsafe_allow_symlinks`

v1.0.0은 `unsafe_allow_symlinks`를 필수 설정 필드로 도입했는데, 이 때문에 TOML 설정 파일 없이 순수 바이너리로 실행하는 노드가 동작하지 않았습니다. 이제 이 필드는 기본값이 off이므로, 명시적으로 opt-in하지 않는 한 심볼릭 링크로 연결된 genesis 파일은 계속 거부됩니다. ([#1601](https://github.com/midnightntwrk/midnight-node/pull/1601))

### Preview genesis and chain spec regenerated

locked-pool 설정을 바로잡기 위해 Preview 네트워크의 genesis와 chain spec을 재생성했습니다. ([#1699](https://github.com/midnightntwrk/midnight-node/pull/1699))

### Preview reserve configuration corrected

Preview의 `reserve-config.json`에서 `asset.asset_name`이 비어 있어야 할 자리에 `NIGHT`로 설정되어 있었습니다. 이번 릴리스는 릴리스 브랜치를 `main`의 수정과 일치시킵니다. ([#1771](https://github.com/midnightntwrk/midnight-node/pull/1771))

### Build and dependency fixes

릴리스 빌드를 수정하기 위한 의존성 업데이트와 함께, 백포트된 ledger 버전 범프가 포함됩니다. ([#1841](https://github.com/midnightntwrk/midnight-node/pull/1841), [#1986](https://github.com/midnightntwrk/midnight-node/pull/1986))

## Known issues

이번 릴리스에는 새로운 known issue가 없습니다. v1.0.0의 `missing field unsafe_allow_symlinks` 오류는 해결되었습니다.
