# Onchain Runtime

:::info[On-chain runtime 릴리스는 이제 Ledger에 포함됩니다]
Ledger 7.0.0부터 on-chain runtime 버전은 이 페이지가 아니라 [Ledger 페이지](./ledger)에 표시됩니다. on-chain runtime은 자체 버전 번호를 유지합니다. 예를 들어 Ledger 8.1.2에는 on-chain runtime 3.1.1이 포함됩니다. 다른 릴리스는 [Component versions by release](./ledger#component-versions-by-release)를 참고하세요. DApp에 사용할 버전을 선택하려면 [호환성 매트릭스](./support-matrix)를 참고하세요.

이 페이지의 릴리스 4.0.0은 2025년 5월 12일 릴리스된 Ledger 4.0.0에서 번호를 가져온 것입니다. 해당 릴리스의 on-chain runtime 패키지는 `@midnight-ntwrk/onchain-runtime` 0.3.0이므로, on-chain runtime 2.0.0과 이후 모든 버전보다 앞섭니다.
:::

Onchain Runtime은 영지식 증명 생성, 트랜잭션 검증, 프라이버시 보호 트랜잭션 처리를 가능하게 하는 Midnight 인프라 컴포넌트입니다.

[관련 문서 링크](/api-reference/onchain-runtime/)
