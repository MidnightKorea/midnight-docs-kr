# Proof Server

:::info[proof server 릴리스는 이제 Ledger에 포함됩니다]
Ledger 7.0.0부터 proof server 릴리스는 이 페이지가 아니라 [Ledger 페이지](./ledger)에 표시됩니다. 7.0.0 이상 버전의 이미지는 Docker Hub에 [`midnightntwrk/proof-server`](https://hub.docker.com/r/midnightntwrk/proof-server)로 제공됩니다. 각 네트워크에서 실행할 버전은 [호환성 매트릭스](./support-matrix)를 참고하세요.

이 페이지의 릴리스는 그 변경 이전의 것입니다. 4.0.0까지의 이미지는 이전 `midnightnetwork/proof-server` 저장소에 있습니다.
:::

Proof Server은 영지식 증명 생성, 트랜잭션 검증, 프라이버시 보호 트랜잭션 처리를 가능하게 하는 Midnight 인프라 컴포넌트입니다.

[관련 문서 링크](../guides/run-proof-server)
