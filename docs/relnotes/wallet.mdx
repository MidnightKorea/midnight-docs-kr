# Wallet SDK

Midnight Wallet SDK은 Midnight 블록체인을 위해 설계된 디지털 지갑의 SDK로, 사용자가 비밀 키를 안전하게 보관하고, 자산을 관리하며, 탈중앙화 애플리케이션과 상호작용할 수 있게 합니다.

[관련 문서 링크](/sdks/official/wallet-developer-guide)

컴포넌트를 다운로드하려면 **Artifacts** 아래의 해당 링크를 클릭하세요.
