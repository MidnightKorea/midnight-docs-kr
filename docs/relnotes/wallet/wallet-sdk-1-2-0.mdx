* **Environment**: Mainnet, Preprod, Preview

## High-level summary

Wallet SDK 1.2.0은 DUST 등록을 수수료 과소추정에 대해 강화하고, 등록 전에 DUST가 적립되기를 기다리는 방법을 호출자에게 제공하는 minor 릴리스입니다. 이 버전부터 패키지는 `@midnightntwrk` npm 스코프로 배포됩니다(이전에는 `@midnight-ntwrk`).

---

## Audience

이번 릴리스는 다음에 해당하는 개발자에게 관련이 깊습니다.

- 지갑이나 DApp에서 DUST 생성을 위해 NIGHT UTXO를 등록하는 개발자
- DUST provisioning 플로우를 자동화하며 등록 시점을 조절해야 하는 개발자

---

## What changed (Summary of updates)

- `WalletFacade.registerNightUtxosForDustGeneration`에서 등록의 `allow_fee_payment`가 자체 수수료보다 낮아져 체인이 `BalanceCheckOverspend`로 제출을 거부하던 race를 수정했습니다. 이제 지갑은 빌드 시점에 수수료를 추정하고, 예약을 되돌린 뒤 제출 전에 예외를 던집니다.
- `WalletFacade.waitForGeneratedDust(utxos, requiredAmount, opts?)`를 추가하여, 호출자가 충분한 DUST가 적립될 때까지 등록을 미룰 수 있게 했습니다. `estimateRegistration`과 함께 사용해 임계값을 정하세요.
- SDK는 이제 `@midnightntwrk` npm 스코프로 배포됩니다. 버전 1.2.0은 두 스코프 모두에서 제공되며, 이후 버전은 새 스코프를 대상으로 합니다.

---

## Breaking changes or required actions

breaking API 변경은 없습니다. 업데이트할 때 새 스코프를 따르도록 의존성을 `@midnightntwrk/wallet-sdk`로 옮기는 것을 고려하세요.
