# Kapa MCP server

Kapa MCP server는 이 문서 사이트의 "Ask AI" 버튼을 구동하는 것과 동일한 Midnight 지식 베이스를 제공합니다. 에디터 안에서 바로 Midnight 문서에 근거한 답변을 AI 코딩 어시스턴트로부터 받을 수 있어, 브라우저 탭을 오가지 않고 질문할 수 있습니다.

Kapa로 옮긴 배경과 Midnight Expert와의 관계는 [마이그레이션 블로그 글](/blog/migrating-to-kapa-and-midnight-expert)에서 확인하세요.

## Install

### Claude Code

명령 하나만 실행하세요.

```bash
claude mcp add --transport http midnight https://midnight.mcp.kapa.ai
```

### Cursor and VS Code

이 사이트의 "Ask AI" 버튼을 열고 "Use MCP"를 클릭한 뒤 "Add to Cursor" 또는 "Add to VS Code"를 선택하세요. 둘 다 클릭 한 번으로 설치됩니다.

### Any other MCP client

JSON 설정에서 remote MCP 서버를 지원하는 클라이언트라면 다음과 같이 직접 추가하세요.

```json
{
  "mcpServers": {
    "midnight": {
      "type": "http",
      "url": "https://midnight.mcp.kapa.ai"
    }
  }
}
```

일부 클라이언트는 이것을 remote 또는 HTTP 서버라고 부르며 transport 필드를 요구하기도 합니다. 어느 경우든 URL은 동일합니다. "Use MCP" 메뉴에서 "Copy MCP URL"을 클릭해, 클라이언트가 요구하는 자리에 붙여 넣어도 됩니다.

## What it covers

Kapa는 선별된 Midnight 자료를 인덱싱합니다. 공식 문서, 직접 고른 핵심 저장소(ledger, midnight.js, 노드), 그리고 백서 같은 개별 자료가 포함됩니다. DUST 생성이 어떻게 동작하는지, witness를 어떻게 구성하는지, 특정 ledger 타입이 무슨 일을 하는지 물어보면 오래된 학습 데이터가 아니라 현재 문서에 근거한 답변을 받습니다.

## Midnight Expert

Compact 컨트랙트를 작성하고 검증하거나, 로컬 devnet을 돌리거나, 오류 코드를 해석하는 등 직접 손을 대는 개발 작업에는 Kapa와 함께 [Midnight Expert](https://midnightntwrk.expert/)를 사용하세요. 설정 방법은 [Midnight agent skills](midnight-agent-skills) 페이지나 [마이그레이션 블로그 글](/blog/migrating-to-kapa-and-midnight-expert)을 참고하세요.
