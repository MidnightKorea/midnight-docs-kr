# Community SDKs

더 넓은 커뮤니티가 만든 라이브러리로 Midnight DApp을 확장하세요. 이 프로젝트들은 컨트랙트 개발 초기에 마주치는 빈틈, 즉 토큰 표준, 접근 제어, 보안 기본 요소를 채워 줍니다. 각 프로젝트는 Midnight Foundation이 아니라 해당 제작자가 직접 유지보수합니다.

:::warning[Community-maintained - not officially supported]

여기 소개된 프로젝트는 Midnight Foundation이 아니라 각 제작자가 유지보수합니다. 감사를 거치지 않았을 수 있고, 최신 Midnight 릴리스와 다른 컴파일러나 런타임 버전을 대상으로 할 수도 있습니다. 통합하기 전에 [호환성 매트릭스](/relnotes/support-matrix)에서 호환 여부를 확인하세요. 문제는 각 프로젝트의 유지보수자에게 직접 제보하세요.

:::

## Eligibility

목록에 오르려면 프로젝트가 잘 알려진 라이선스로 오픈소스여야 하고, 활발히 유지보수되어야 하며, 공개 이슈 트래커를 갖춰야 합니다. 또한 문서화된 Compact 컴파일러나 런타임 버전 범위를 대상으로 해야 합니다. 감사 여부는 필수가 아니지만, 각 프로젝트 페이지에서 그 상태를 눈에 띄게 표시합니다.
