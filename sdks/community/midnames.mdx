Midnames는 Midnight Network과 상호작용할 때 도움이 되는 여러 도구와 서비스를 제공합니다. 여기에는 Midnight address에 사람이 읽기 쉬운 이름을 등록하는 name service와, Compact 코드를 작성하고 컴파일할 수 있는 playground가 포함됩니다.

## Compact Playground

playground는 [playground.midnames.com](https://playground.midnames.com/)에서 사용할 수 있습니다. 이곳에서 Compact 코드를 작성하고 컴파일하며, 내장 Simulator로 코드와 상호작용할 수 있습니다.

playground의 "Examples" 섹션에서 [Compact 문서](https://docs.midnight.com/compact)에 나오는 예제들을 확인할 수 있습니다. 직접 프로젝트를 만들어 다른 사람과 공유할 수도 있습니다.

### Compilation

Compact 코드는 remote compiler 또는 local compiler로 컴파일할 수 있습니다. remote compiler는 코드를 서버로 보내 처리합니다. local compiler는 브라우저에서 실행되는 WASM 기반 버전을 사용하는데, 제대로 된 오류 메시지를 생성하지 못하는 등 몇 가지 제약이 있습니다.

:::caution[Local compilation]
local compiler는 느려서 큰 contract를 컴파일할 때 시간이 꽤 걸릴 수 있습니다. 생성되는 오류 메시지도 도움이 되지 않습니다.
:::

## Name service

Midnames는 [midnight.domains](https://midnight.domains/)에서 name service도 운영합니다. 이 name service로 Midnight address에 연결되는 사람이 읽기 쉬운 이름을 등록할 수 있어, Midnight Network의 contract와 address를 더 편하게 다룰 수 있습니다.

도메인 구매 방법은 [docs.midnight.domains](https://docs.midnight.domains/guides/buy_domain/)의 가이드에서 확인할 수 있습니다.

### SDK

midnight.domains SDK는 npm 패키지로 제공됩니다. 다음 명령으로 설치할 수 있습니다:

```bash
npm install @midnames/sdk
```

이 SDK는 이름 등록, 이름을 address로 resolve, 도메인에 메타데이터 추가 등 name service와 상호작용하는 함수들을 제공합니다. SDK 문서는 [docs.midnight.domains](https://docs.midnight.domains/reference/resolve/)에서 확인할 수 있습니다.
