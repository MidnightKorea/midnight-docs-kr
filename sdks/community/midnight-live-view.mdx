# Midnight Live View

[Midnight Live View](https://github.com/Midnight-Scripts/Midnight-Live-View)는 Midnight validator 노드를 위한 터미널 기반 모니터링 대시보드입니다. 노드 상태, 블록 생성, 피어 연결, 시스템 자원을 실시간으로 보여주며 매초 갱신합니다.

이 프로젝트는 두 개의 셸 스크립트로 이루어집니다.

- <strong>`LiveView.sh`</strong>: [CNTool의 gLiveView](https://cardano-community.github.io/guild-operators/Scripts/gliveview/)에서 영감을 받은 실시간 대시보드로, 노드 버전, 가동 시간, 블록 데이터, 피어 수, 시스템 지표를 보여줍니다.
- <strong>`simple_block_monitor.sh`</strong>: 컨테이너 로그를 tail하고 로컬 JSON 파일에 기록해 블록을 영구적으로 추적하는 백그라운드 프로세스입니다. 블록 데이터는 Docker 재시작 후에도 유지됩니다.

:::warning[Community-maintained, no license]

이 프로젝트는 Midnight Foundation이 아니라 [Midnight-Scripts](https://github.com/Midnight-Scripts)가 유지보수합니다. 저장소에는 현재 라이선스가 명시되어 있지 않습니다. 이 도구는 감사를 거치지 않았습니다. 어떤 환경에서든 의존하기 전에 직접 검증하세요.

:::

## Prerequisites

도구를 사용하기 전에 다음을 갖췄는지 확인하세요.

- 실행 중인 Midnight validator 노드(기본값으로 `midnight`이라는 이름의 Docker 컨테이너).
- `jq`와 `curl` 설치(Ubuntu/Debian에서는 `sudo apt install jq curl`, macOS에서는 `brew install jq curl`).
- Docker 설치 및 실행.
- `LiveView.sh`와 같은 디렉터리에 있는 `partner-chains-public-keys.json` 파일.

## Compatibility

| Component | Version | Notes |
|---|---|---|
| Tool version | `0.2.1` | 정식 릴리스 없음. 코드는 `main` 브랜치에서 가져옵니다. |
| Tested node version | `0.12.0` | `cab67f3b`, `29935d2f` 빌드에서 테스트됨. |
| Network | Testnet | 문서상 Mainnet 지원 없음. |
| Platforms | Linux, macOS | 설치 명령은 Ubuntu/Debian과 macOS(Homebrew) 기준입니다. |

## Node configuration

대시보드는 노드의 RPC 엔드포인트에서 데이터를 읽습니다. RPC 인터페이스를 노출하려면 `.envrc` 파일의 `APPEND_ARGS` 변수를 수정해야 합니다.

:::danger[Security: unsafe RPC methods]

아래 설정은 `--unsafe-rpc-external`과 `--rpc-methods=Unsafe`를 활성화하는데, 이는 공개 접근에 안전하지 않은 RPC 메서드를 노출합니다. 단일 서버 환경이라면 로컬 모니터링 용도로 무방합니다. 다중 서버 환경이라면 RPC 접근을 신뢰할 수 있는 IP로만 제한하세요.

:::

단일 서버 환경이라면 `APPEND_ARGS`에 다음을 추가하세요.

```bash
--unsafe-rpc-external --rpc-methods=Unsafe --rpc-cors all
```

두 서버 환경이라면 전체 설정 방법을 [프로젝트 README](https://github.com/Midnight-Scripts/Midnight-Live-View#readme)에서 확인하세요.

## Installation

두 스크립트를 내려받고 실행 권한을 부여합니다.

```bash
wget -O ./LiveView.sh https://raw.githubusercontent.com/Midnight-Scripts/Midnight-Live-View/refs/heads/main/LiveView.sh
wget -O ./simple_block_monitor.sh https://raw.githubusercontent.com/Midnight-Scripts/Midnight-Live-View/refs/heads/main/simple_block_monitor.sh
chmod +x LiveView.sh simple_block_monitor.sh
```

## Run the dashboard

대시보드만 사용하는 기본 모니터링은 다음과 같습니다.

```bash
./LiveView.sh
```

영구 블록 추적(권장)을 원하면, 블록 모니터를 먼저 실행하세요.

```bash
./simple_block_monitor.sh start
./LiveView.sh
```

블록 모니터는 백그라운드에서 실행되며 `all_blocks.json`에 기록합니다. `start`, `stop`, `status`, `run`(대화형 모드)으로 관리하세요.

## Dashboard features

대시보드는 다음 정보를 매초 갱신해 보여줍니다.

- <strong>Node info</strong>: 버전, 가동 시간, 컨테이너 시작 시각.
- <strong>Security</strong>: 노드 키(마스킹됨), 포트, 키 상태.
- <strong>Registration</strong>: 현재 등록 상태.
- <strong>Block data</strong>: 누적 블록(모니터링 시작 이후 총합), 생성한 블록(Docker 재시작 이후), 최신·확정 블록 번호, 동기화 상태.
- <strong>Network</strong>: 피어 수와 대화형 피어 상세(`p` 키).
- <strong>System</strong>: CPU, 메모리, 디스크 사용량.

종료하려면 `q`, 피어 상세를 켜고 끄려면 `p`를 누르세요.

## Configuration

환경 변수로 기본값을 재정의할 수 있습니다.

| Variable | Default | Purpose |
|---|---|---|
| `CONTAINER_NAME` | `midnight` | validator 노드의 Docker 컨테이너 이름. |
| `PORT` | `9944` | 대시보드가 연결하는 RPC 포트. |
| `USE_DOCKER` | `true` | Docker가 아닌 노드 환경이면 `false`로 설정. |

## Files created at runtime

블록 모니터는 작업 디렉터리에 세 개의 파일을 만듭니다.

| File | Purpose |
|---|---|
| `all_blocks.json` | 중복을 막는 영구 블록 데이터베이스. |
| `block_monitor.log` | 모니터 활동 로그. |
| `.block_monitor.pid` | 프로세스 추적 파일. |
